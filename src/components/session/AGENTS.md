# session

## Purpose
Daily learning session workflow. Shows today's session with 4 sequential phases (retrieval → learning → micro-task → reflection), RL-generated daily plan, spaced repetition review queue, and session completion form.

## Key Files

| File | Description |
|------|-------------|
| `TodayView.tsx` | Main view: loads today's session, daily plan, review queue, quick stats |
| `DailyPlanCard.tsx` | RL scheduler recommendation with time allocation breakdown per phase |
| `PhaseCard.tsx` | Individual phase: type label, timer, content area, score input, completion |
| `ReviewQueue.tsx` | Topics sorted by recall probability (lowest first = most urgent) |
| `QuickStats.tsx` | Streak count, weekly mastery delta, attendance percentage |
| `SessionComplete.tsx` | Wrap-up form: confidence slider, energy level, notes textarea |

## For AI Agents

### Working In This Directory
- Phases must be completed in order: retrieval (5min) → learning (25min) → micro-task (12min) → reflection (5min)
- Review queue uses real spaced repetition data from `useIntelligence`
- Daily plan generated by RL scheduler — shows recommended time allocation
- Session completion triggers: RL state update, behavioral log, weekly aggregate recalculation

### Known Issues
- Daily plan uses zeroed RL defaults until first session is completed (rl_state not seeded)
- Topics not assigned to specific sessions (topics_json always None)
